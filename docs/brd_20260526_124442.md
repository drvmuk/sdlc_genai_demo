# Business Objectives
- Load customer and order CSVs into Delta tables.
- Cleanse data by removing "Null"/null literals and duplicates.
- Enrich order data by computing TotalAmount = PricePerUnit × Qty.
- Join customer and order to create an ordersummary table.
- Apply SCD Type 2 handling for customer changes in ordersummary.
- Aggregate daily customer spend in customeraggregatespend table.
- Complete the full pipeline using Delta Live Tables.

# Business Requirements

### BR-APP-001 — Source Ingestion
- Description: Load customer and order source CSV data into Delta tables from designated filesystem locations.
- Business Value: Establishes foundational datasets for downstream processing and analytics.
- Priority: High

### BR-APP-002 — Table Schema Compliance
- Description: Create and enforce schemas for customer (CustId, Name, EmailId, Region) and order (OrderId, ItemName, PricePerUnit, Qty, Date, CustId) tables.
- Business Value: Ensures data consistency and accurate processing.
- Priority: High

### BR-APP-003 — Computed Field TotalAmount
- Description: Calculate TotalAmount on the order table as PricePerUnit × Qty.
- Business Value: Supports downstream financial and aggregation analytics.
- Priority: High

### BR-APP-004 — Data Cleansing Operations
- Description: Remove "Null"/null literals and duplicate records from customer and order tables.
- Business Value: Maintains data quality and reliability.
- Priority: High

### BR-APP-005 — Ordersummary Target Table Creation
- Description: Create ordersummary table in specified catalog/schema, enabling historical and joined customer-order data.
- Business Value: Provides centralized view for reporting and SCD processing.
- Priority: High

### BR-APP-006 — SCD Type 2 Change Handling for customer
- Description: Set previous customer records inactive and new records active upon changes; update StartDate and EndDate; maintain full history in ordersummary.
- Business Value: Ensures historical customer changes are auditable.
- Priority: High

### BR-APP-007 — Join Logic
- Description: Join customer and order tables on CustId to populate ordersummary.
- Business Value: Integrates customer identity with transaction data.
- Priority: High

### BR-APP-008 — Aggregation Processing
- Description: Aggregate data from ordersummary to customeraggregatespend table by Name and Date, summing TotalAmount.
- Business Value: Delivers summarized spend data for analysis.
- Priority: High

### BR-APP-009 — Implementation via Delta Live Tables
- Description: Execute all pipeline steps using Delta Live Tables as per requirements.
- Business Value: Leverages managed data pipelines for reliability and automation.
- Priority: High
