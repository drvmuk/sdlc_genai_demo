# Executive Summary
- This BRD outlines business needs for the Application, specifically ingesting customer and order CSV data into Delta tables.
- The solution will include data cleansing, computation of TotalAmount, joining logic with SCD Type 2 history, and daily customer spend aggregation, all implemented via Delta Live Tables.

# Business Objectives
- Load customer and order CSV data into Delta tables.
- Cleanse data by removing null literals and duplicates.
- Compute TotalAmount in the order table.
- Join customer and order data applying SCD Type 2 for customers.
- Aggregate daily spend in a customeraggregatespend table.
- Implement the pipeline using Delta Live Tables.

# In-Scope
- Source ingestion from specified file system locations.
- Creation and management of Delta tables for customer, order, ordersummary, and customeraggregatespend.
- Data cleansing according to requirements.
- Addition of computed TotalAmount.
- Implementation of SCD Type 2 logic for historical tracking.
- Aggregation for spend reporting.
- Guided by Delta Live Tables instructions.

# Business Requirements

### BR-APP-001 — Source Ingestion
- Description: Load customer and order CSVs from specified file system paths into Delta tables.
- Business Value: Ensures reliable intake and storage as structured data.
- Priority: High

### BR-APP-002 — Data Schemas
- Description: Define required columns for customer (CustId, Name, EmailId, Region) and order (OrderId, ItemName, PricePerUnit, Qty, Date, CustId).
- Business Value: Standardizes data for downstream processing.
- Priority: High

### BR-APP-003 — Data Cleansing
- Description: Remove "Null"/Null literals and duplicate records from customer and order data.
- Business Value: Improves data quality and trustworthiness.
- Priority: High

### BR-APP-004 — Computation of TotalAmount
- Description: Add computed column TotalAmount (PricePerUnit × Qty) to order data.
- Business Value: Enables financial metrics for orders.
- Priority: High

### BR-APP-005 — Target Table Creation: ordersummary
- Description: Create table ordersummary in gen_ai_poc_databrickscoe.sdlc_wizard as the join of customer and order data.
- Business Value: Provides unified view of customer and order info.
- Priority: High

### BR-APP-006 — SCD Type 2 Customer Dimension Logic
- Description: For customer attribute changes, close past records (Inactive), add new (Active), update StartDate and EndDate, and keep all history in ordersummary.
- Business Value: Maintains compliance and historical traceability.
- Priority: High

### BR-APP-007 — ordersummary Schema Enforcement
- Description: Populate ordersummary with CustId, Name, EmailId, Region, OrderId, ItemName, PricePerUnit, Qty, Date.
- Business Value: Ensures data consistency for reporting/analytics.
- Priority: High

### BR-APP-008 — Spend Aggregation: customeraggregatespend
- Description: Aggregate ordersummary by Name and Date to produce customeraggregatespend with sum(TotalAmount).
- Business Value: Delivers actionable insights on customer spending.
- Priority: High

### BR-APP-009 — Implementation Modality
- Description: All above requirements are implemented using Delta Live Tables as per guided steps.
- Business Value: Ensures managed and reproducible pipeline operations.
- Priority: High
