Requirements Traceability Matrix (RTM)

Legend:
- BR: Business Requirement
- FR: Functional Requirement
- DC: Design Component
- US: User Story / Feature
- TC: Test Case
- TS: Test Scenario
- CM: Code Module

Definitions:
- Requirement ID: Unique identifier for requirement
- Requirement Description: Description
- Business Priority: High, Medium, Low
- Source: BRD/Stakeholder
- Functional Area: Process area impacted
- Design Component: Architecture/module/solution mapping
- User Story/Feature Mapping: Agile/Story ticket ID
- Code Module/Repository Reference: Source code mapping
- Test Scenario ID: High-level test group
- Test Case ID: Atomic test
- Test Status: Not Started/In Progress/Pass/Fail
- Dependencies: Upstream requirements
- Risks: Associated project/product risks
- Comments: Additional notes
