# Executive Summary
- Privacy Impact Assessment conducted for Application.
- Project processes customer and order data, performing ETL (Extract, Transform, Load) pipelines using Delta Live Tables.
- Data sources are CSVs ingested and transformed, with SCD Type 2 applied to maintain historical record lineage.

# Project Overview and Purpose of Processing
- Ingest customer and order CSVs into Delta tables.
- Cleanse, transform, and join data to create enriched datasets for analytics and reporting.

# Description of Personal Data Categories Processed
- Names (customer)
- EmailId (customer)
- Region (customer)
- Purchase details: OrderId, ItemName, PricePerUnit, Qty, Date, CustId (order)

# Data Flow Architecture (collection, storage, processing, sharing)
- Data collected from CSV files at defined file system locations.
- Loaded into Delta tables for customer and order datasets.
- Data cleansing (removal of "Null" values and duplicates).
- Computed columns (TotalAmount) and joins to build summary and aggregate tables.
- No explicit external data sharing defined; stored and processed within the Delta Live Tables environment.

# Risk Identification
- Confidentiality risks: Unauthorized access to tables.
- Integrity risks: Data corruption during pipeline transformations.
- Re-identification risks: Via EmailId, Name, or region if datasets are combined externally.
- Access management risks: Insufficient table/data access controls.

# Impact Assessment with Severity & Likelihood Scoring
- Confidentiality Risk: Moderate severity, moderate likelihood if access not hardened.
- Integrity Risk: Low to moderate severity, low likelihood with validated pipelines.
- Re-identification Risk: Low severity, low likelihood within prescribed use.
- Access Risk: Moderate severity, moderate likelihood if controls are not defined.

# Mitigation Strategies & Security Controls (Encryption, DLP, IAM, Logging)
- Ensure storage encryption at rest and transit within Delta infrastructure.
- Implement role-based access on Delta tables.
- Establish data access logging and periodic review.
- Data Loss Prevention: Restrict export and external sharing.
- Audit logs for all ETL operations and data transformations.

# Residual Risk Evaluation
- If above controls are implemented, residual risk reduced to low.
- Unmitigated risks remain where controls are not documented in current requirements.
