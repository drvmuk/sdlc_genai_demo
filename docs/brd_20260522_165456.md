# Document Control
- System Name: Application

# Executive Summary
- This Business Requirements Document (BRD) defines all requirements for the Application system, focusing on ingesting customer and order CSV data into Delta tables.
- The document outlines processes for cleansing, transforming, and aggregating data, including SCD Type 2 handling and pipeline orchestration using Delta Live Tables.

# Business Objectives
- Load source customer and order CSV files into Delta tables.
- Cleanse data by removing "Null" values and duplicates.
- Compute TotalAmount for orders by multiplying PricePerUnit and Qty.
- Join customer and order data to form an ordersummary table with SCD Type 2 history for customers.
- Aggregate customer spend per day in the customeraggregatespend table.
- Implement the pipeline via Delta Live Tables.

# In-Scope
- Ingestion of customer and order CSVs from specified file paths.
- Creation and management of Delta tables: customer, order, ordersummary, customeraggregatespend.
- Data cleansing operations.
- Calculation logic for TotalAmount.
- Join processing and SCD Type 2 implementation for customer data.
- Aggregation of customer spend by Name and Date.
- All orchestration via Delta Live Tables.

# Business Requirements

### BR-APP-001 — Source Ingestion
- Description: Load source CSVs into Delta tables for customer and order data from specified paths.
- Business Value: Enables structured ingestion and consistency of data for downstream processes.
- Priority: High

### BR-APP-002 — Data Schema Enforcement
- Description: Enforce defined schemas for customer and order tables.
- Business Value: Ensures data integrity and enables trusted analytics.
- Priority: High

### BR-APP-003 — Computed Attribute Creation
- Description: Compute TotalAmount in order table as PricePerUnit × Qty.
- Business Value: Provides necessary metric for aggregation and reporting.
- Priority: High

### BR-APP-004 — Data Cleansing
- Description: Remove records with "Null" values and duplicates in customer and order tables.
- Business Value: Improves data quality and reliability.
- Priority: High

### BR-APP-005 — ordersummary Table Creation
- Description: Join customer and order tables on CustId and implement SCD Type 2 for customer changes.
- Business Value: Maintains historical accuracy for analytic reporting.
- Priority: High

### BR-APP-006 — SCD Type 2 Maintenance
- Description: Ensure previous customer versions are marked Inactive and new versions Active; manage StartDate and EndDate.
- Business Value: Supports historical data tracking and auditability.
- Priority: High

### BR-APP-007 — Aggregate Table Creation
- Description: Create customeraggregatespend table aggregating spend per customer per date.
- Business Value: Delivers actionable spend analytics for business stakeholders.
- Priority: High

### BR-APP-008 — End-to-End Pipeline Automation
- Description: Implement the above business requirements using Delta Live Tables.
- Business Value: Enables automated, reliable, and maintainable data processing.
- Priority: High
