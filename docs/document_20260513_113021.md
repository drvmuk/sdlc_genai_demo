- System Overview
  - The Application processes source CSV data, loads it into Delta tables (customer, order), applies transformation and cleansing, creates summary and aggregate spend tables, and manages SCD type 2 history using Delta Live Tables.

- User Roles
  - Data Engineer
  - Data Analyst
  - Administrator

- Functional Scope
  - Ingest customer and order data from CSV files.
  - Clean and transform ingested data.
  - Manage Slowly Changing Dimension (SCD) type 2 ordersummary table.
  - Aggregate and store customer spending.
  - Automate ETL pipeline using Delta Live Tables.

- Functional Requirements
