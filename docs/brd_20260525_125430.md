# Document Control
- System Name: Application

# Executive Summary
- This BRD defines requirements for ingesting customer and order CSV data into Delta tables, applying data cleansing, computing a TotalAmount, joining for an SCD Type 2 ordersummary table, and aggregating daily spend for customeraggregatespend, leveraging Delta Live Tables.
- System Name: Application

# Business Objectives
- Load customer and order data from CSV to Delta tables.
- Cleanse data to remove "Null"/Null literals and duplicates.
- Calculate and enrich each order with a TotalAmount field.
- Join customer and order data to create a comprehensive ordersummary table.
- Implement SCD Type 2 to preserve customer history in ordersummary.
- Aggregate daily customer spend in customeraggregatespend.
- Provide an end-to-end automated pipeline using Delta Live Tables.

# In-Scope
- Ingest customer and order CSVs into respective Delta tables.
- Execute cleansing routines on customer and order data.
- Add computed TotalAmount to orders.
- Join customer and order on CustId, producing ordersummary.
- Apply SCD Type 2 change handling for customer dimension.
- Aggregate daily spend into customeraggregatespend.
- Implementation adherence to Delta Live Tables.

- Security, access, SLAs, monitoring, or alerting.
- Performance tuning or scaling configuration.
- Scheduling, orchestration, or DevOps beyond using Delta Live Tables.
- Data quality metrics outside stated cleansing.
- Dashboard, reporting, or analytics visualization.

# Business Requirements

### BR-APP-001 — Ingest Customer Data
- Description: Ingest customer CSV from /Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata into Delta table 'customer'.
- Business Value: Enables structured, accessible customer data management.
- Priority: High

### BR-APP-002 — Ingest Order Data
- Description: Ingest order CSV from /Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata into Delta table 'order'.
- Business Value: Enables structured, accessible order data management.
- Priority: High

### BR-APP-003 — Data Cleansing for Customer
- Description: Remove "Null"/Null literals and duplicate records from customer data.
- Business Value: Improves data quality and reliability for downstream processes.
- Priority: High

### BR-APP-004 — Data Cleansing for Order
- Description: Remove "Null"/Null literals and duplicate records from order data.
- Business Value: Ensures order data consistency and integrity.
- Priority: High

### BR-APP-005 — Add Computed TotalAmount
- Description: Add computed field TotalAmount = PricePerUnit × Qty to order table.
- Business Value: Enables accurate financial analytics and aggregations.
- Priority: High

### BR-APP-006 — Create Ordersummary Table
- Description: Create ordersummary table by joining customer and order data.
- Business Value: Provides a 360º view of customer order activity.
- Priority: High

### BR-APP-007 — Implement SCD Type 2 for Customer in Ordersummary
- Description: Manage historical changes in customer attributes with SCD Type 2 (active/inactive records, start/end dates).
- Business Value: Preserves full customer change history for audits and analytics.
- Priority: High

### BR-APP-008 — Create Customer Aggregate Spend Table
- Description: Create customeraggregatespend table with daily total spend grouped by customer Name and Date.
- Business Value: Supports business decision-making via aggregate spend analytics.
- Priority: High

### BR-APP-009 — End-to-End Pipeline with Delta Live Tables
- Description: Implement all ingestion, cleansing, transformation, joining, SCD, and aggregation steps using Delta Live Tables.
- Business Value: Enables reliable, automated data processing workflows.
- Priority: High

# Assumptions & Constraints
- Only requirements explicitly described are assumed.
- Implementation modality is Delta Live Tables as instructed.
