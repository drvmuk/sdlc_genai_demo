# Executive Summary
- This BRD defines the ingestion, cleansing, enrichment, and aggregation of customer and order data from CSV sources into Delta tables using Delta Live Tables.
- The Application system will enable structured, history-aware, and aggregated datasets for enterprise data processing.

# Business Objectives
- Load source CSVs into Delta tables for customer and order data
- Cleanse data by removing "Null"/Null literals and duplicates
- Enrich orders with computed TotalAmount as PricePerUnit × Qty
- Produce ordersummary table by joining customer and order on CustId with SCD Type 2 history
- Create customeraggregatespend table aggregating spend per Name per Date
- Execute all steps end-to-end via Delta Live Tables
