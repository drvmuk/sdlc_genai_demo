* Dataset Name: Order Data
* Location: order_table (database table)
* Format: Delta Lake
* Description: Order data with columns date, quantity, and ordered

* **6. Target Data Details**
* Output Name: Filtered Order Data
* Location: /output/filtered_orders (file path)
* Format: Parquet
* Description: Filtered order data with quantity greater than 25

* Create a Spark SQL query to select data from the order table
* Specify columns to be retrieved (date, quantity, and ordered)
* Add a filter condition to the query to filter data based on quantity greater than 25
* Execute the Spark SQL query to retrieve the filtered data
* Return the resulting dataset

* Step: Create Spark SQL query
* Description: Generate a Spark SQL query to read data from the order table
* Transformation Logic: Use Spark SQL to select data from the order table
* Step: Apply filter condition
* Description: Filter data based on quantity greater than 25
* Transformation Logic: Use Spark SQL filter condition to include only rows where quantity > 25
