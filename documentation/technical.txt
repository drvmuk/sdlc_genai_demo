Here is the Technical Requirement Document (TRD) based on the provided Functional Requirement Document (FRD):

* **Technical Requirement ID**: TR-FIN-001
* **Related Functional Requirement(s)**: FR-FIN-001
* **Objective**: Implement a data processing job to transform and load data from Everest ECC source tables into the Finance table.

* **Target Cluster Configuration**:
	+ Cluster Name: Finance Data Processing Cluster
	+ Databricks Runtime Version: 7.3.x-scala2.12
	+ Node Type: Standard_DS3_v2
	+ Driver Node: Standard_DS3_v2 (1 node)
	+ Worker Nodes: Standard_DS3_v2 (2-5 nodes)
	+ Autoscaling: Enabled
	+ Auto Termination: 30 minutes
	+ Libraries Installed: PySpark, pandas, NumPy

* **Source Data Details**:
	+ FAGLFLEXA table: Available in the Everest ECC database, in CSV format.
	+ BSEG table: Available in the Everest ECC database, in CSV format.
	+ Golden Entity view: Available in the Golden database, in Parquet format.
	+ GL view: Available in the Golden database, in Parquet format.
	+ Trading Partner view: Available in the Golden database, in Parquet format.
	+ s_shared.v_actual_exchange_rate_bpc: Available in the BPC database, in Parquet format.

* **Target Data Details**:
	+ Finance table: Located in the Finance database, in Parquet format.

* **Job Flow / Pipeline Stages**:
	+ Retrieve source data from FAGLFLEXA and BSEG tables.
	+ Apply filters and derive fields.
	+ Calculate GainLossGC and GainLossLC.
	+ Derive additional fields.
	+ Load transformed data into the Finance table.

* **Data Transformations / Business Logic**:
	+ Step 1: Join FAGLFLEXA with BSEG on document number, fiscal year, and company code for records with XBILK = 'X'.
	+ Step 2: Filter out records with CompCode starting with '8%'.
	+ Step 3: Derive Legal Entity by reading Entity golden view and exclude archived Golden Entity values.
	+ Step 4: Derive GLAccount by selecting distinct FAGLFLEXA.DOCNR where FAGLFLEXA.RACCT belongs to golden acct realized and unrealized.
	+ Step 5: Calculate GainLossGC using BPC exchange rates and FiscalYearPeriod.
	+ Step 6: Derive GainLossLC by applying logic based on LocalCurrency.
	+ Step 7: Derive additional fields such as GainLossTC, OffsetAccount, and GoldenOffsetAccount.

* **Error Handling and Logging**:
	+ Log errors and exceptions to a designated error log table.
	+ Implement retry mechanism for failed tasks.
	+ Send notifications to designated personnel in case of job failure.
