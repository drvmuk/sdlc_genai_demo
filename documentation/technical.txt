* **TR-DLT-001: Load Customer and Order Data from CSV to Delta Tables**
	+ **Related Functional Requirement(s):** FR-DLT-001
	+ **Objective:** Implement a Delta Live Table pipeline to read customer and order data from CSV files, load it into delta tables, and perform data cleansing and transformation.
	+ **Target Cluster Configuration:**
		- Cluster Name: Gen AI POC Databricks Cluster
		- Databricks Runtime Version: 11.3.x-scala2.12
		- Node Type: Standard_DS4_v2
		- Driver Node: Standard_DS4_v2
		- Worker Nodes: 2-4 Standard_DS4_v2
		- Autoscaling: Enabled
		- Auto Termination: 30 minutes
		- Libraries Installed: delta-lake, pyspark
	+ **Source Data Details:**
		- Customer Data: `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata`, CSV
		- Order Data: `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata`, CSV
	+ **Target Data Details:**
		- Customer Table: `customer`, Delta Table
		- Order Table: `order`, Delta Table
	+ **Job Flow / Pipeline Stages:**
		- Read customer data from CSV into delta table `customer`
		- Read order data from CSV into delta table `order`
		- Add `TotalAmount` column to `order` table
		- Remove null and duplicate records from `customer` and `order` tables
	+ **Data Transformations / Business Logic:**
		- Step 1: Read CSV data into delta tables
		- Step 2: Add `TotalAmount` column to `order` table by multiplying `PricePerUnit` and `Qty`
		- Step 3: Remove null and duplicate records from `customer` and `order` tables using `dropDuplicates()` and `dropna()`
	+ **Error Handling and Logging:**
		- Log errors to a designated log table or file
		- Implement try-except blocks to handle data transformation errors
