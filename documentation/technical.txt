  * Stage 1: Create intermediate table `s_shared.sales_orders_hdr_itm_lots`

    * Apply transformation logic as specified in the mapping document
  * Stage 2: Create main table `sales_orders`
    * Retrieve data from `s_shared.sales_orders_hdr_itm_lots` and other source tables
    * Perform left joins with other tables as per the mapping document
    * Apply filters and transformation logic as specified
  * Stage 3: Generate SQL query

  * Step: Handle complex logic for columns like `SiteId`, `SalesDistributionChannel`, and `ExchangeRate`
