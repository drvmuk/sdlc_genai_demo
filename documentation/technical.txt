	+ Cluster Name: SQL Generation Cluster

	+ Node Type: Standard_DS3_v2
	+ Driver Node: Standard_DS3_v2
	+ Worker Nodes: 2-4 (autoscaling)
	+ Autoscaling: Enabled
	+ Auto Termination: 30 minutes
	+ Libraries Installed: Spark SQL, Scala

* **Source Data Details**:
	+ Dataset Name: Tabular Mapping Document
	+ Location: /mnt/mapping-document/tabular-mapping.csv
	+ Format: CSV
	+ Description: Contains the column mappings and transformation logic
	+ Dataset Name: Source Tables
	+ Location: /mnt/source-data/
	+ Format: Parquet
	+ Description: Contains the source data for the sales orders

* **Target Data Details**:
	+ Output Name: SQL Query
	+ Location: /mnt/output/sql-query.sql
	+ Format: SQL
	+ Description: The generated SQL query

	+ Description: The intermediate table used to generate the final output
	+ Output Name: Main Table "sales_orders_comp"
	+ Location: /mnt/output/sales_orders_comp
	+ Format: Parquet
	+ Description: The final output table

* **Job Flow / Pipeline Stages**:
	+ Stage 1: Retrieve the tabular mapping document
	+ Stage 2: Apply transformation logic to generate target columns
	+ Stage 3: Perform required joins between tables
	+ Stage 4: Filter data based on common filter conditions
	+ Stage 5: Generate SQL query to create intermediate table "sales_orders_comp_stg"
	+ Stage 6: Generate SQL query to create main table "sales_orders_comp"
	+ Stage 7: Output the complete SQL query

* **Data Transformations / Business Logic**:
	+ Step: Apply transformation logic to generate target columns
	+ Description: Apply concatenation, conditional logic, and date conversions as specified in the tabular mapping document
	+ Transformation Logic: Use Spark SQL to apply the transformation logic, e.g., CONCAT(referenceto,refno), IF, CASE, cast(to_date(from_unixtime(unix_timestamp(cast(a.dateupd as string), 'yyyyMMdd'))) as date)

* **Error Handling and Logging**:

	+ Provide detailed error messages and stack traces for debugging purposes
