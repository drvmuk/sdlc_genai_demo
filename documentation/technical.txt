## 7. Job Flow / Pipeline Stages
* Stage 1: Execute SQL query to create intermediate table s_shared.sales_orders_hdr_itm_lots
* Stage 2: Execute SQL query to create main table s_shared.sales_orders
* Stage 3: Validate data completeness and integrity
* Stage 4: Log execution metrics and results

## 8. Data Transformations / Business Logic
* Step 1: Create Intermediate Table
  * Description: Transform and join base tables to create intermediate table
  * Transformation Logic:
    * Filter plooh where DATA_OPERATION is not 'D'
    * Join with plool on refto and refno
    * Apply string concatenations for OrderNumber
    * Implement conditional logic using IF statements
    * Calculate OpenQuantityOrginal using b.ordqx-b.tcqtx-b.tdqtx
    * Perform date conversions using cast, to_date, from_unixtime, and unix_timestamp
    * Create all 25 target columns with appropriate transformations

* Step 2: Create Main Table
  * Description: Transform and join intermediate table with reference tables
  * Transformation Logic:
    * Filter intermediate table for records within last 3 years
    * Join with multiple reference tables for enrichment
    * Apply conditional logic for SiteId and ExchangeRate
    * Perform date conversions as specified
    * Set default values for specified columns
    * Handle NULL values according to mapping requirements
    * Create all 145 target columns with appropriate transformations

## 9. Error Handling and Logging
* Implement pre-execution validation to verify source table existence and accessibility
* Log query execution start and end times
* Capture and log record counts for source and target tables
* Implement error handling for join failures and data type conversion issues
* Log detailed error messages with table and column information for troubleshooting
* Implement data quality checks to validate key business rules
* Create summary execution report with success/failure status
