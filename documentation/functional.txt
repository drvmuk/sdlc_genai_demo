**FR-FIN-001: Generate Finance Data**

**Title**: Generate Finance data by transforming and processing data from Everest ECC source tables FAGLFLEXA and BSEG.

**Description**: The system must generate finance data by applying transformation logic to data from FAGLFLEXA and BSEG tables in the Everest ECC source schema, based on specific filters and joins.

**Preconditions**:

* FAGLFLEXA and BSEG tables exist in the Everest ECC source schema.
* Data is available in FAGLFLEXA and BSEG tables.
* Fiscal Year and Posting Period parameters are provided.
* Golden views (Entity, GL, Trading Partner) are available and up-to-date.

**Main Flow / Functional Steps**:

1. **Retrieve data from FAGLFLEXA and BSEG tables**:
	* Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR.
	* Filter data where RLDNR = '0L' and XBILK = 'X'.
2. **Apply transformation logic**:
	* Derive FiscalYear, PostingPeriod, DocumentNumber, CompCode, LegalEntity, GLAccount, GoldenGLAcct, TradingPartner, GoldenTradingPartner, GainLossGC, GainLossLC, GainLossTC, LocalCurrency, TransactionCurrency, OffsetAccount, GoldenOffsetAccount, Offset Account LC Amount, Offset Clearing Document Number, and SourceSystem based on the provided logic.
	* Exclude CompCode that starts with '8'.
	* Filter out archived Golden Entity values.
3. **Calculate GainLossGC**:
	* Use BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) to calculate GainLossGC from GainLossLC.
4. **Determine OffsetAccount**:
	* Apply logic to find offset account for Realized and Unrealized accounts based on v_realized_unrealized_glaccts.Realized_Unrealized value.
	* Sort and pick the offset account with the maximum TC amount.
5. **Store the transformed data**:
	* Store the transformed data in the target Finance table.

**Additional Requirements**:

* Use Spark SQL to generate the code.
* Use the provided parameters (Fiscal Year and Posting Period) in the data transformation logic.
* Use Golden views to derive certain fields (e.g., LegalEntity, GoldenGLAcct, GoldenTradingPartner).
