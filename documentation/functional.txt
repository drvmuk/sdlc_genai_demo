**FR-FIN-001: Load Finance Data from Everest ECC**

**Title:** Load Finance Data from Everest ECC into Finance Table

**Description:** The system must load finance data from Everest ECC into the Finance table by joining FAGLFLEXA and BSEG tables based on specific conditions and applying various transformations.

**Preconditions:**

* The system has access to Everest ECC source schema.
* FAGLFLEXA and BSEG tables exist in the Everest ECC schema.
* The necessary parameters (FY, Posting Period) are available.
* Golden views (Entity, GL, Trading Partner) are available.

**Main Flow / Functional Steps:**

1. **Retrieve Data from FAGLFLEXA and BSEG Tables:**
	* Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR.
	* Filter records where RLDNR = '0L' and XBILK = 'X'.
2. **Apply Filters and Transformations:**
	* Exclude records where RBUKRS starts with '8%'.
	* Convert Company Code to Golden Entity using the Entity golden view.
	* Filter out archived Golden Entity values.
	* Convert FAGLFLEXA.RACCT to Golden GL account using the Golden GL view.
	* Convert FAGLFLEXA.RASSC to Golden Trading Partner using the Golden Trading Partner view.
3. **Calculate GainLossGC and GainLossLC:**
	* Retrieve exchange rates from s_shared.v_actual_exchange_rate_bpc.
	* Calculate GainLossGC using GainLossLC and exchange rate.
	* Apply special logic for GainLossLC when LocalCurrency is in a specific list of currencies.
4. **Calculate GainLossTC:**
	* Apply special logic for GainLossTC when TransactionalCurrency is in a specific list of currencies.
5. **Determine Offset Account:**
	* Apply logic to find offset account for Realized and Unrealized accounts based on v_realized_unrealized_glaccts and BSEG tables.
	* Convert OffsetAccount to Golden GL account using the Golden GL view.
6. **Load Data into Finance Table:**
	* Store the transformed data in the Finance table.

**Detailed Requirements:**

* The system must join FAGLFLEXA and BSEG tables on the specified conditions.
* The system must apply the specified filters (RLDNR = '0L', XBILK = 'X', RBUKRS not starting with '8%').
* The system must convert Company Code to Golden Entity using the Entity golden view.
* The system must filter out archived Golden Entity values.
* The system must convert FAGLFLEXA.RACCT to Golden GL account using the Golden GL view.
* The system must convert FAGLFLEXA.RASSC to Golden Trading Partner using the Golden Trading Partner view.
* The system must calculate GainLossGC and GainLossLC using the specified logic.
* The system must calculate GainLossTC using the specified logic.
* The system must determine the Offset Account using the specified logic.
* The system must convert OffsetAccount to Golden GL account using the Golden GL view.
* The system must load the transformed data into the Finance table.
