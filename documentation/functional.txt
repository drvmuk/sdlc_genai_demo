Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD) and adhering to the specified template:

**1. Requirement ID**
FR-FIN-001

**2. Title**
Populate Finance Table with Transformed Data from ECC Everest

**3. Description**
The system must extract data from the ECC Everest system, apply specified transformations, and load the transformed data into the Finance table.

**4. Preconditions**

* The ECC Everest system is available and contains the required data.
* The necessary views (e.g., Entity golden view, Golden GL view, Golden Trading Partner view) are available and contain the required data.
* The BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) are available.

**5. Main Flow / Functional Steps**

1. **Retrieve Data from ECC Everest**
	* Extract data from FAGLFLEXA and BSEG tables.
	* Apply filter: RLDNR = '0L'.
	* Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR, and XBILK = 'X'.
2. **Apply Transformations**
	* Derive FiscalYear from FY parameter.
	* Derive PostingPeriod from Posting Period parameter.
	* Map SourceFiscalYear to FAGLFLEXA.RYEAR.
	* Map SourcePeriod to FAGLFLEXA.POPER.
	* Map DocumentNumber to FAGLFLEXA.DOCNR.
	* Map CompCode to FAGLFLEXA.RBUKRS, excluding values starting with '8'.
	* Derive LegalEntity by reading Entity golden view and converting Company Code to Golden Entity; exclude archived Golden Entity values.
	* Map GLAccount to FAGLFLEXA.RACCT, selecting distinct values where FAGLFLEXA.RACCT belongs to golden acct realized and unrealized.
	* Map GoldenGLAcct by converting FAGLFLEXA.RACCT to golden GL account using Golden GL view.
	* Map TradingPartner to FAGLFLEXA.RASSC.
	* Map GoldenTradingPartner by converting FAGLFLEXA.RASSC to golden trading partner using Golden Trading Partner view.
	* Calculate GainLossGC using BPC exchange rates and GainLossLC.
	* Derive LocalCurrency by reading Entity view (GFA Revenue).
	* Map GainLossLC to HSL; apply multiplication factor if LocalCurrency is in specified list.
	* Map GainLossTC to TSL; apply multiplication factor if TransactionalCurrency is in specified list.
	* Map TransactionCurrency to FAGLFLEXA.RWCUR.
3. **Determine Offset Account**
	* For Realized accounts, find offset account using v_realized_unrealized_glaccts and BSEG; apply sorting and selection logic.
	* For Unrealized accounts, find offset account using v_realized_unrealized_glaccts and BSEG; apply sorting and selection logic.
	* Map GoldenOffsetAccount by converting OffsetAccount to golden GL account using Golden GL view.
4. **Load Transformed Data into Finance Table**
	* Map Offset Account LC Amount to BSEG.DMBTR.
	* Map Offset Account TC Amount to BSEG.WRBTR.
	* Map Offset Clearing Document Number to BSEG.AUGBL.
	* Set SourceSystem to 'ECC Everest'.
5. **Store the Transformed Data**
	* Load the transformed data into the Finance table.

The system must execute these steps to populate the Finance table with the required data.
