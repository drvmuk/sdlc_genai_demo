Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD) "Coding Requirements" section:

**FR-DLT-001: Load Customer and Order Data to Delta Tables**

* **Title:** Load Customer and Order Data to Delta Tables
* **Description:** The system must read source CSV data from a volume and load it into Delta tables for customer and order data.
* **Preconditions:**
	+ CSV files are available at the specified locations: `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata` and `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata`
	+ Delta tables are available for customer and order data
* **Main Flow / Functional Steps:**
	1. Read customer CSV data from `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata` and load it into a Delta table named "customer".
	2. Read order CSV data from `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata` and load it into a Delta table named "order".
	3. Add a new column "TotalAmount" to the "order" table, calculated as the product of "PricePerUnit" and "Qty" columns.

**FR-DLT-002: Clean and Process Customer and Order Data**

* **Title:** Clean and Process Customer and Order Data
* **Description:** The system must remove null and duplicate records from customer and order data.
* **Preconditions:**
	+ Customer and order data are loaded into Delta tables
* **Main Flow / Functional Steps:**
	1. Remove null records from the "customer" and "order" tables.
	2. Remove duplicate records from the "customer" and "order" tables.

**FR-DLT-003: Create Ordersummary Table and Load Joined Data**

* **Title:** Create Ordersummary Table and Load Joined Data
* **Description:** The system must create an "ordersummary" table if it does not exist and load joined customer and order data into it using SCD Type 2.
* **Preconditions:**
	+ Customer and order data are cleaned and processed
	+ "ordersummary" table does not exist or is available for loading
* **Main Flow / Functional Steps:**
	1. Create the "ordersummary" table if it does not exist in the catalog "gen_ai_poc_databrickscoe" and schema "sdlc_wizard".
	2. Join customer and order data using the "CustId" field.
	3. Load the joined data into the "ordersummary" table using SCD Type 2.

**FR-DLT-004: Update Ordersummary Table on Customer Data Change**

* **Title:** Update Ordersummary Table on Customer Data Change
* **Description:** The system must update the "ordersummary" table whenever there is a change in the customer table.
* **Preconditions:**
	+ Customer data is updated
	+ "ordersummary" table is available
* **Main Flow / Functional Steps:**
	1. Identify changes in the customer table.
	2. Update the "ordersummary" table by making old records inactive and new records active.
	3. Update StartDate and EndDate accordingly to maintain history.

**FR-DLT-005: Create Customer Aggregate Spend Table and Load Aggregated Data**

* **Title:** Create Customer Aggregate Spend Table and Load Aggregated Data
* **Description:** The system must create a "customeraggregatespend" table if it does not exist and load aggregated data from the "ordersummary" table.
* **Preconditions:**
	+ "ordersummary" table is available and loaded with data
	+ "customeraggregatespend" table does not exist or is available for loading
* **Main Flow / Functional Steps:**
	1. Create the "customeraggregatespend" table if it does not exist in the catalog "gen_ai_poc_databrickscoe" and schema "sdlc_wizard".
	2. Aggregate the "TotalAmount" column from the "ordersummary" table and group by "Name" and "Date" columns.
	3. Load the aggregated data into the "customeraggregatespend" table.

**FR-DLT-006: Implement Delta Live Tables**

* **Title:** Implement Delta Live Tables
* **Description:** The system must implement Delta Live Tables for the above-mentioned functionality.
* **Preconditions:**
	+ All previous steps are completed successfully
* **Main Flow / Functional Steps:**
	1. Implement Delta Live Tables for loading customer and order data.
	2. Implement Delta Live Tables for cleaning and processing customer and order data.
	3. Implement Delta Live Tables for creating and loading the "ordersummary" table.
	4. Implement Delta Live Tables for updating the "ordersummary" table on customer data change.
	5. Implement Delta Live Tables for creating and loading the "customeraggregatespend" table.
