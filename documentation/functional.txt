**FR-FIN-001: Generate Spark SQL Code for Finance Data Transformation**

**Description:** 
The system must generate Spark SQL code to transform finance data from the source tables FAGLFLEXA and BSEG in the Everest ECC schema into the target Finance table.

**Preconditions:**

* The source tables FAGLFLEXA and BSEG exist in the Everest ECC schema.
* The required parameters (FY, Posting Period) are available.
* The golden views (Entity, GL, Trading Partner) are available.

**Main Flow / Functional Steps:**

* Step 1: Filter FAGLFLEXA records based on RLDNR = '0L'.
* Step 2: Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, RYEAR = GJAHR, and XBILK = 'X'.
* Step 3: Apply the following transformations:
	+ FiscalYear: FY parameter.
	+ PostingPeriod: Posting Period parameter.
	+ SourceFiscalYear: FAGLFLEXA.RYEAR = FY Parameter.
	+ SourcePeriod: FAGLFLEXA.POPER = Posting Period parameter.
	+ DocumentNumber: FAGLFLEXA.DOCNR.
	+ CompCode: FAGLFLEXA.RBUKRS (exclude RBUKRS like '8%').
	+ LegalEntity: Convert Company Code to Golden Entity using Entity golden view and filter out archived Golden Entity values.
	+ GLAccount: FAGLFLEXA.RACCT (select distinct FAGLFLEXA.DOCNR where FAGLFLEXA.RACCT belongs to golden acct realized and unrealized).
	+ GoldenGLAcct: Convert FAGLFLEXA.RACCT to golden GL account using golden GL view.
	+ TradingPartner: FAGLFLEXA.RASSC.
	+ GoldenTradingPartner: Convert FAGLFLEXA.RASSC to golden trading partner using golden trading partner view.
	+ GainLossGC: Calculate GC values from LC values using BPC exchange rates (s_shared.v_actual_exchange_rate_bpc).
	+ GainLossLC: FAGLFLEXA.HSL (apply special logic for certain LocalCurrency values).
	+ LocalCurrency: Derive Local Currency from Entity view (GFA Revenue).
	+ GainLossTC: FAGLFLEXA.TSL (apply special logic for certain TransactionalCurrency values).
	+ TransactionCurrency: FAGLFLEXA.RWCUR.
	+ OffsetAccount: Determine offset account for Realized/Unrealized accounts using BSEG.HKONT and specific logic.
	+ GoldenOffsetAccount: Convert OffsetAccount to golden GL account using golden GL view.
	+ Offset Account LC Amount: BSEG.DMBTR.
	+ Offset Account TC Amount: BSEG.WRBTR.
	+ Offset Clearing Document Number: BSEG.AUGBL.
	+ SourceSystem: 'ECC Everest'.
* Step 4: Generate Spark SQL code to perform the above transformations and load the data into the target Finance table.

**Additional Requirements:**

* The system must handle the logic for determining the offset account for Realized and Unrealized accounts as specified.
* The system must apply the special logic for certain LocalCurrency and TransactionalCurrency values when calculating GainLossLC and GainLossTC.
