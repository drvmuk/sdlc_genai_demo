Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD) "Coding Requirements" section.

**FR-DELTA-001**
* **Title**: Load Source CSV Data to Delta Tables
* **Description**: The system must read source CSV data from a specified volume and load it into Delta tables for customer and order data.
* **Preconditions**: 
  * Source CSV files are available at the specified locations: `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata` and `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata`.
  * The schema of the customer and order CSV files matches the expected schema.
* **Main Flow / Functional Steps**:
  * Read customer CSV data from `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata`.
  * Read order CSV data from `/Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata`.
  * Load the data into Delta tables `customer` and `order` respectively.

**FR-DELTA-002**
* **Title**: Cleanse Customer and Order Data
* **Description**: The system must remove "Null"/Null and duplicate records from both customer and order Delta tables.
* **Preconditions**: 
  * Customer and order Delta tables are loaded with data.
* **Main Flow / Functional Steps**:
  * Remove rows with "Null"/Null values from the `customer` table.
  * Remove duplicate records from the `customer` table.
  * Remove rows with "Null"/Null values from the `order` table.
  * Remove duplicate records from the `order` table.

**FR-DELTA-003**
* **Title**: Create ordersummary Table
* **Description**: The system must create the `ordersummary` table if it does not exist in the specified catalog and schema.
* **Preconditions**: 
  * The catalog `gen_ai_poc_databrickscoe` and schema `sdlc_wizard` exist.
* **Main Flow / Functional Steps**:
  * Check if the `ordersummary` table exists in the `gen_ai_poc_databrickscoe` catalog and `sdlc_wizard` schema.
  * Create the `ordersummary` table if it does not exist.

**FR-DELTA-004**
* **Title**: Load ordersummary Table
* **Description**: The system must join customer and order data using the "CustId" field and load the data into the `ordersummary` SCD type 2 table.
* **Preconditions**: 
  * Customer and order Delta tables are cleansed.
  * The `ordersummary` table exists.
* **Main Flow / Functional Steps**:
  * Join the `customer` and `order` tables on the "CustId" field.
  * Load the joined data into the `ordersummary` SCD type 2 table.

**FR-DELTA-005**
* **Title**: Update ordersummary SCD Type 2 Table on Customer Change
* **Description**: The system must update the `ordersummary` SCD type 2 table whenever there is a change in the customer table.
* **Preconditions**: 
  * The `ordersummary` table is loaded with data.
  * A change is detected in the `customer` table.
* **Main Flow / Functional Steps**:
  * Identify the changed records in the `customer` table.
  * Update the corresponding records in the `ordersummary` table by marking old records as Inactive and new records as Active.
  * Update the StartDate and EndDate accordingly.

**FR-DELTA-006**
* **Title**: Create customeraggregatespend Table
* **Description**: The system must create the `customeraggregatespend` table if it does not exist in the specified catalog and schema.
* **Preconditions**: 
  * The catalog `gen_ai_poc_databrickscoe` and schema `sdlc_wizard` exist.
* **Main Flow / Functional Steps**:
  * Check if the `customeraggregatespend` table exists in the `gen_ai_poc_databrickscoe` catalog and `sdlc_wizard` schema.
  * Create the `customeraggregatespend` table with columns "Name", "TotalAmount", and "Date" if it does not exist.

**FR-DELTA-007**
* **Title**: Load customeraggregatespend Table
* **Description**: The system must aggregate the "TotalAmount" column from the `ordersummary` table and load the data into the `customeraggregatespend` table.
* **Preconditions**: 
  * The `ordersummary` table is loaded with data.
  * The `customeraggregatespend` table exists.
* **Main Flow / Functional Steps**:
  * Aggregate the "TotalAmount" column from the `ordersummary` table by "Name" and "Date".
  * Load the aggregated data into the `customeraggregatespend` table.
