Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD) "Coding Requirements" section:

**1. Requirement ID**
FR-FIN-001

**2. Title**
Generate Finance Data from ECC Everest Source System

**3. Description**
The system must generate finance data by extracting and transforming relevant information from the ECC Everest source system, specifically from the FAGLFLEXA and BSEG tables, based on specified filters and joins.

**4. Preconditions**

* FAGLFLEXA and BSEG tables are available in the ECC Everest source system.
* Relevant data is populated in the FAGLFLEXA and BSEG tables.
* Golden views (e.g., Entity, GL, Trading Partner) are available and populated.
* BPC exchange rates are available in the s_shared.v_actual_exchange_rate_bpc table.

**5. Main Flow / Functional Steps**

1. **Retrieve Data from FAGLFLEXA and BSEG Tables**
	* Join FAGLFLEXA with BSEG on DOCNR, RBUKRS, and RYEAR (Fiscal Year) columns.
	* Filter data where RLDNR = '0L' and XBILK = 'X'.
2. **Apply Filters and Transformations**
	* Exclude records where RBUKRS starts with '8%'.
	* Convert Company Code to Golden Entity using the Entity golden view.
	* Filter out archived Golden Entity values.
	* Convert FAGLFLEXA.RACCT to Golden GL account using the Golden GL view.
	* Convert FAGLFLEXA.RASSC to Golden Trading Partner using the Golden Trading Partner view.
3. **Calculate GainLossGC and GainLossLC**
	* Retrieve exchange rates from s_shared.v_actual_exchange_rate_bpc table.
	* Calculate GainLossGC using the exchange rate and GainLossLC.
	* Apply special logic for certain Local Currencies (e.g., ADP, AFA, BEF, etc.).
4. **Determine Offset Account**
	* For Realized accounts, find the offset account using BSEG.HKONT and specific logic (e.g., sorting by absolute value of BSEG.WRBTR and checking for non-NULL BSEG.AUGBL).
	* For Unrealized accounts, find the offset account using BSEG.HKONT and specific logic (e.g., sorting by absolute value of BSEG.WRBTR and checking for NULL BSEG.AUGBL).
5. **Convert Offset Account to Golden GL Account**
	* Use the Golden GL view to convert the Offset Account to a Golden GL Account.
6. **Generate Output**
	* Produce the final output with the required fields, including FiscalYear, PostingPeriod, DocumentNumber, CompCode, LegalEntity, GLAccount, GoldenGLAcct, TradingPartner, GoldenTradingPartner, GainLossGC, GainLossLC, GainLossTC, TransactionCurrency, OffsetAccount, GoldenOffsetAccount, Offset Account LC Amount, Offset Clearing Document Number, and SourceSystem.

The system should execute these steps to generate the finance data from the ECC Everest source system.
