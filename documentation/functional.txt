**FR-FIN-001: Populate Finance Table with Transformed Data**

**Title:** Populate Finance Table with Transformed Data from Everest ECC Source Tables

**Description:** The system must populate the Finance table with transformed data from the FAGLFLEXA and BSEG source tables in the Everest ECC schema, applying specified filters, joins, and transformation logic.

**Preconditions:**

* FAGLFLEXA and BSEG tables exist in the Everest ECC schema.
* Data is available in the FAGLFLEXA and BSEG tables.
* FY and Posting Period parameters are provided.
* Golden views (Entity, GL, Trading Partner) are available and populated.

**Main Flow / Functional Steps:**

1. **Retrieve Data from Source Tables:**
	* Retrieve data from FAGLFLEXA and BSEG tables in the Everest ECC schema.
	* Apply filter: RLDNR = '0L'.
	* Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR, and XBILK = 'X'.
2. **Apply Transformation Logic:**
	* For each record:
		+ Derive FiscalYear from FY parameter.
		+ Derive PostingPeriod from Posting Period parameter.
		+ Derive DocumentNumber from FAGLFLEXA.DOCNR.
		+ Derive CompCode from FAGLFLEXA.RBUKRS, excluding values starting with '8'.
		+ Derive LegalEntity by reading Entity golden view and converting Company Code to Golden Entity; exclude archived Golden Entity values.
		+ Derive GLAccount from FAGLFLEXA.RACCT, selecting distinct values where FAGLFLEXA.RACCT belongs to golden acct realized and unrealized.
		+ Derive GoldenGLAcct by converting FAGLFLEXA.RACCT to golden GL account using golden GL view.
		+ Derive TradingPartner from FAGLFLEXA.RASSC.
		+ Derive GoldenTradingPartner by converting FAGLFLEXA.RASSC to golden trading partner using golden trading partner view.
		+ Calculate GainLossGC using BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) and FiscalYearPeriod.
		+ Derive GainLossLC from HSL; if LocalCurrency is in specified list, multiply PeriodLC by 100.
		+ Derive LocalCurrency by reading Entity view (GFA Revenue).
		+ Derive GainLossTC from TSL; if TransactionalCurrency is in specified list, multiply PeriodTC by 100.
		+ Derive TransactionCurrency from RTCUR.
		+ Derive OffsetAccount using logic for Realized or Unrealized accounts.
		+ Derive GoldenOffsetAccount by converting OffsetAccount to golden GL account using golden GL view.
		+ Derive Offset Account LC Amount from BSEG.DMBTR.
		+ Derive Offset Account TC Amount from BSEG.WRBTR.
		+ Derive Offset Clearing Document Number from BSEG.AUGBL.
3. **Populate Finance Table:**
	* Insert transformed data into the Finance table.
	* Set SourceSystem to 'ECC Everest'.

**Additional Requirements:**

* Ensure data consistency and integrity during the data transformation and loading process.
* Handle errors and exceptions that may occur during data retrieval, transformation, or loading.
