Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD):

**1. Requirement ID**
FR-FIN-001

**2. Title**
Populate Finance Table with Data from Everest ECC

**3. Description**
The system must extract data from Everest ECC source tables (FAGLFLEXA and BSEG), apply transformations, and load the data into the Finance table.

**4. Preconditions**

* Source data is available in Everest ECC tables FAGLFLEXA and BSEG.
* Fiscal Year and Posting Period parameters are provided.
* Golden views (Entity, GL, Trading Partner) are available and up-to-date.
* BPC exchange rates are available in s_shared.v_actual_exchange_rate_bpc.

**5. Main Flow / Functional Steps**

* **Step 1: Filter and Join Source Data**
	+ Filter FAGLFLEXA records where RLDNR = '0L'.
	+ Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR.
	+ Filter joined records where XBILK = 'X'.
* **Step 2: Apply Transformations**
	+ Derive FiscalYear from FY parameter.
	+ Derive PostingPeriod from Posting Period parameter.
	+ Derive DocumentNumber from FAGLFLEXA.DOCNR.
	+ Derive CompCode from FAGLFLEXA.RBUKRS (excluding values starting with '8').
	+ Derive LegalEntity by converting Company Code to Golden Entity using Entity golden view.
	+ Filter out archived Golden Entity values.
	+ Derive GLAccount from FAGLFLEXA.RACCT (selecting distinct DOCNR where RACCT belongs to golden acct realized and unrealized).
	+ Derive GoldenGLAcct by converting FAGLFLEXA.RACCT to golden GL account using golden GL view.
	+ Derive TradingPartner from FAGLFLEXA.RASSC.
	+ Derive GoldenTradingPartner by converting FAGLFLEXA.RASSC to golden trading partner using golden trading partner view.
	+ Calculate GainLossGC using BPC exchange rates and GainLossLC.
	+ Derive GainLossLC from FAGLFLEXA.HSL (applying special logic for certain Local Currencies).
	+ Derive LocalCurrency from Entity view (GFA Revenue).
	+ Derive GainLossTC from FAGLFLEXA.WSL (applying special logic for certain Transactional Currencies).
	+ Derive TransactionCurrency from FAGLFLEXA.RWCUR.
	+ Derive OffsetAccount using logic for Realized and Unrealized accounts.
	+ Derive GoldenOffsetAccount by converting OffsetAccount to golden GL account using golden GL view.
	+ Derive Offset Account LC Amount from BSEG.DMBTR.
	+ Derive Offset Account TC Amount from BSEG.WRBTR.
	+ Derive Offset Clearing Document Number from BSEG.AUGBL.
* **Step 3: Load Data into Finance Table**
	+ Load transformed data into the Finance table.
	+ Set SourceSystem to 'ECC Everest'.
