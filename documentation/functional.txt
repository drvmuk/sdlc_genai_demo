**FR-FIN-001: Generate Finance Data**

**Title:** Generate Finance Data for Reporting

**Description:** The system must generate finance data by transforming and processing data from source tables FAGLFLEXA and BSEG, applying specified business rules and logic.

**Preconditions:**

* Source data is available in FAGLFLEXA and BSEG tables.
* Fiscal Year (FY) parameter is provided.
* Posting Period parameter is provided.
* Golden views (Entity, GL, Trading Partner) are available and up-to-date.

**Main Flow / Functional Steps:**

1. **Retrieve Source Data:**
	* Retrieve data from FAGLFLEXA and BSEG tables.
	* Apply filter: RLDNR = '0L'.
	* Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR, and XBILK = 'X'.
2. **Apply Transformation Logic:**
	* For each row:
		+ Derive FiscalYear from FY parameter.
		+ Derive PostingPeriod from Posting Period parameter.
		+ Derive DocumentNumber from FAGLFLEXA.DOCNR.
		+ Derive CompCode from FAGLFLEXA.RBUKRS, excluding values starting with '8'.
		+ Derive LegalEntity by reading Entity golden view and converting Company Code to Golden Entity; exclude archived Golden Entity values.
		+ Derive GLAccount from FAGLFLEXA.RACCT, selecting distinct values where FAGLFLEXA.RACCT belongs to golden realized and unrealized accounts.
		+ Derive GoldenGLAcct by converting FAGLFLEXA.RACCT to golden GL account using golden GL view.
		+ Derive TradingPartner from FAGLFLEXA.RASSC.
		+ Derive GoldenTradingPartner by converting FAGLFLEXA.RASSC to golden trading partner using golden trading partner view.
		+ Calculate GainLossGC using BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) and BS exchange rate (AVG) for FiscalYearPeriod.
		+ Derive GainLossLC from HSL.
		+ Derive LocalCurrency by reading Entity view (GFA Revenue).
		+ Derive GainLossTC from TSL.
		+ Derive TransactionCurrency from RTCUR.
		+ Derive OffsetAccount using logic for Realized and Unrealized accounts.
		+ Derive GoldenOffsetAccount by converting OffsetAccount to golden GL account using golden GL view.
		+ Derive Offset Account LC Amount from BSEG.DMBTR.
		+ Derive Offset Account TC Amount from BSEG.WRBTR.
		+ Derive Offset Clearing Document Number from BSEG.AUGBL.
3. **Store Transformed Data:**
	* Store the transformed data in the target Finance table.

**Additional Requirements:**

* The system must handle multiple offset accounts for a document number/company code/Fiscal Year combination and pick the correct one based on the specified logic.
* The system must apply the correct exchange rate to calculate GainLossGC.
