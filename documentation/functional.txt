**FR-DLP-001: Load Customer and Order Data into Delta Tables**

* **Title:** Load Customer and Order Data into Delta Tables and Generate Order Summary
* **Description:** The system must read customer and order data from CSV files, load it into delta tables, remove null and duplicate records, and generate an order summary by joining the customer and order data.

* **Preconditions:**
	+ CSV files containing customer and order data are available at the specified locations: `Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/customerdata` and `Volumes/gen_ai_poc_databrickscoe/sdlc_wizard/orderdata`.
	+ The schema of the customer and order data is known: `Custld, Name, Emailld, Region` for customer and `Orderld, ItemName, PricePerUnit, Qty, Date, CustId` for order.

* **Main Flow / Functional Steps:**
	+ Read customer and order data from CSV files into delta tables.
	+ Remove null and duplicate records from both customer and order delta tables.
	+ Check if the `ordersummary` table exists in the `gen_ai_poc_databrickscoe` catalog and `sdlc_wizard` schema; create it if not.
	+ Join customer and order data using the `Custld` field.
	+ Load the joined data into the `ordersummary` table, which is an SCD type 2 table.
	+ Implement SCD type 2 logic to update the `ordersummary` table when there are changes in the customer table:
		- Make old records inactive.
		- Make new records active.
		- Update `StartDate` and `EndDate` accordingly.

**FR-DLP-002: Update Order Summary for Customer Changes**

* **Title:** Update Order Summary for Customer Changes
* **Description:** The system must update the `ordersummary` table whenever there are changes in the customer table.

* **Preconditions:**
	+ The `ordersummary` table exists in the `gen_ai_poc_databrickscoe` catalog and `sdlc_wizard` schema.
	+ The customer table has been updated.

* **Main Flow / Functional Steps:**
	+ Detect changes in the customer table.
	+ Update the `ordersummary` table according to the SCD type 2 logic:
		- Identify the affected records.
		- Make old records inactive by updating `EndDate`.
		- Insert new records with updated customer information, marking them as active and setting `StartDate` and `EndDate` accordingly.
