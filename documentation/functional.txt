Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD):

**FR-FIN-001**

**Title:** Generate Finance Data for ECC Everest Source System

**Description:** The system must generate finance data by transforming and processing data from the ECC Everest source system, specifically from the FAGLFLEXA and BSEG tables, and loading it into the target Finance table.

**Preconditions:**

* FAGLFLEXA and BSEG tables are available in the ECC Everest source system.
* FY (Fiscal Year) and Posting Period parameters are provided.
* Golden views (Entity, GL, Trading Partner) are available and up-to-date.
* s_shared.v_actual_exchange_rate_bpc and s_shared.v_revenue_entity_bpc tables are available.

**Main Flow / Functional Steps:**

1. **Retrieve Data from Source Tables:**
	* Retrieve data from FAGLFLEXA and BSEG tables from the ECC Everest source system.
	* Apply filter RLDNR = '0L' on FAGLFLEXA table.
2. **Join FAGLFLEXA and BSEG Tables:**
	* Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR.
	* Filter joined data to include only records with XBILK = 'X'.
3. **Apply Transformation Logic:**
	* For each field in the target Finance table, apply the transformation logic as specified:
		+ FiscalYear: Use FY parameter.
		+ PostingPeriod: Use Posting Period parameter.
		+ DocumentNumber: Use FAGLFLEXA.DOCNR.
		+ CompCode: Use FAGLFLEXA.RBUKRS, excluding values starting with '8'.
		+ LegalEntity: Read Entity golden view to convert Company Code to Golden Entity; exclude archived Golden Entity values.
		+ GLAccount: Use FAGLFLEXA.RACCT, selecting distinct values where FAGLFLEXA.RACCT belongs to golden acct realized and unrealized.
		+ GoldenGLAcct: Convert FAGLFLEXA.RACCT to golden GL account by reading golden GL view.
		+ TradingPartner: Use FAGLFLEXA.RASSC.
		+ GoldenTradingPartner: Convert FAGLFLEXA.RASSC to golden trading partner by reading golden trading partner view.
		+ GainLossGC: Calculate GC values from LC values using BPC exchange rates.
		+ GainLossLC: Use HSL; if LocalCurrency is in specified list, multiply PeriodLC by 100.
		+ LocalCurrency: Read Entity view (GFA Revenue) to derive Local Currency.
		+ GainLossTC: Use TSL; if TransactionalCurrency is in specified list, multiply PeriodTC by 100.
		+ TransactionCurrency: Use FAGLFLEXA.RWCUR.
		+ OffsetAccount: Apply logic to find offset account for Realized and Unrealized accounts.
		+ GoldenOffsetAccount: Convert OffsetAccount to golden GL account by reading golden GL view.
		+ Offset Account LC Amount: Use BSEG.DMBTR.
		+ Offset Account TC Amount: Use BSEG.WRBTR.
		+ Offset Clearing Document Number: Use BSEG.AUGBL.
4. **Load Transformed Data into Target Finance Table:**
	* Load the transformed data into the target Finance table.
5. **Set SourceSystem Field:**
	* Set SourceSystem field to 'ECC Everest'.
