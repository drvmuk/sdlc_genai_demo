**FR-FIN-001: Populate Finance Table**

**Title:** Populate Finance table with data from FAGLFLEXA and BSEG tables with required transformations.

**Description:** The system must populate the Finance table with data from FAGLFLEXA and BSEG tables by applying the specified filters, joins, and transformations.

**Preconditions:**

* FAGLFLEXA and BSEG tables are available in the Everest ECC source schema.
* FY and Posting Period parameters are provided.
* Golden views (Entity, GL, Trading Partner) are available.

**Main Flow / Functional Steps:**

1. **Retrieve Data from FAGLFLEXA and BSEG tables:**
	* Join FAGLFLEXA with BSEG on DOCNR=BELNR, RBUKRS=BUKRS, and RYEAR=GJAHR.
	* Filter records with RLDNR = '0L' and XBILK = 'X'.
2. **Apply Filters:**
	* Filter out records with CompCode starting with '8%'.
	* Exclude Golden Entity values that are archived (HistEntity = 'Y').
3. **Transform Data:**
	* Convert Company Code to Golden Entity using Entity golden view.
	* Convert FAGLFLEXA.RACCT to Golden GL account using Golden GL view.
	* Convert FAGLFLEXA.RASSC to Golden Trading Partner using Golden Trading Partner view.
	* Calculate GainLossGC using BPC exchange rates (s_shared.v_actual_exchange_rate_bpc).
	* Calculate GainLossLC and GainLossTC based on LocalCurrency and TransactionalCurrency.
	* Determine OffsetAccount for Realized and Unrealized accounts based on specified logic.
	* Convert OffsetAccount to Golden GL account using Golden GL view.
4. **Populate Finance Table:**
	* Insert transformed data into the Finance table.

**Detailed Transformation Steps:**

* For GainLossGC calculation:
	+ Retrieve exchange rate from s_shared.v_actual_exchange_rate_bpc using BS exchange rate (AVG) and FiscalYearPeriod.
	+ Multiply GainLossLC by exchange rate.
* For GainLossLC calculation:
	+ If LocalCurrency is in the specified list, multiply PeriodLC by 100.
* For GainLossTC calculation:
	+ If TransactionalCurrency is in the specified list, multiply PeriodTC by 100.
* For OffsetAccount determination:
	+ For Realized accounts, sort BSEG.WRBTR (absolute value) in descending order and pick the GL Account with Max TC Amount and clearing document number.
	+ For Unrealized accounts, sort BSEG.WRBTR (absolute value) in descending order and pick the GL Account with Max TC Amount and no clearing document number.

**Postconditions:**

* Finance table is populated with transformed data.
* Data is available for further processing and analysis.
