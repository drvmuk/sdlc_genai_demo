**1. Requirement ID**
FR-SQL-001

**2. Title**
Generate Spark SQL Code to Read Order Data with Quantity Filter

**3. Description**
The system must generate Spark SQL code to read data from the order table with columns date, quantity, and ordered, applying a filter condition on quantity greater than 25.

**4. Preconditions**
* The order table exists in the database.
* The order table has columns date, quantity, and ordered.
* Spark SQL is installed and configured.

**5. Main Flow / Functional Steps**

* The system generates Spark SQL code to read data from the order table.
* The system applies a filter condition to the data to include only rows where quantity is greater than 25.
* The system retrieves the filtered data using Spark SQL.
* The system returns the resulting dataset.

Alternatively, the Main Flow / Functional Steps can be broken down into more detailed steps as follows:

* The system creates a Spark SQL query to select data from the order table.
* The system specifies the columns to be retrieved (date, quantity, and ordered).
* The system adds a filter condition to the query to filter data based on quantity greater than 25.
* The system executes the Spark SQL query to retrieve the filtered data.
* The system returns the resulting dataset.
