Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD) and adhering to the specified template:

**1. Requirement ID**
FR-FIN-001

**2. Title**
Load Finance Data from ECC Everest into Finance Table

**3. Description**
The system must load finance data from ECC Everest into the Finance table by joining FAGLFLEXA and BSEG tables based on specific conditions and applying various transformations.

**4. Preconditions**

* FAGLFLEXA and BSEG tables are available in the ECC Everest source system.
* FY parameter (Fiscal Year) is provided.
* Posting Period parameter is provided.
* Golden views (Entity, GL, Trading Partner) are available and up-to-date.
* BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) are available.

**5. Main Flow / Functional Steps**

1. **Retrieve Data from FAGLFLEXA and BSEG Tables**
	* Join FAGLFLEXA with BSEG on DOCNR=BELNR, RBUKRS=BUKRS, and RYEAR=GJAHR.
	* Filter records where RLDNR = '0L' and XBILK = 'X'.
2. **Apply Filters and Transformations**
	* Filter out records where RBUKRS starts with '8%'.
	* Convert Company Code to Golden Entity using Entity golden view.
	* Exclude records where Golden Entity is archived (HistEntity = 'Y' in s_shared.v_revenue_entity_bpc).
	* Select distinct DOCNR where RACCT belongs to golden acct realized and unrealized.
3. **Calculate GainLossGC and GainLossLC**
	* Retrieve exchange rate from BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) using BS exchange rate (AVG) and FiscalYearPeriod.
	* Calculate GainLossGC = GainLossLC * exchange rate.
	* If LocalCurrency is in the specified list, multiply PeriodLC by 100 to get GainLossLC.
4. **Calculate GainLossTC**
	* If TransactionalCurrency is in the specified list, multiply PeriodTC by 100 to get GainLossTC.
5. **Determine Offset Account**
	* For Realized accounts, find offset account using BSEG.HKONT where v_realized_unrealized_glaccts.Realized_Unrealized = 'R'.
	* For Unrealized accounts, find offset account using BSEG.HKONT where v_realized_unrealized_glaccts.Realized_Unrealized = 'U'.
	* Sort descending TC amount BSEG.WRBTR (absolute value) and clearing document BSEG.AUGBL (not NULL for Realized, NULL for Unrealized).
	* Pick the BSEG.HKONT GL Account with Max TC Amount and with/without clearing document number.
6. **Convert Offset Account to Golden GL Account**
	* Use golden GL view to convert OffsetAccount to GoldenOffsetAccount.
7. **Load Data into Finance Table**
	* Load the transformed data into the Finance table with the required fields (FiscalYear, PostingPeriod, DocumentNumber, CompCode, LegalEntity, GLAccount, GoldenGLAcct, TradingPartner, GoldenTradingPartner, GainLossGC, GainLossLC, GainLossTC, LocalCurrency, TransactionCurrency, OffsetAccount, GoldenOffsetAccount, Offset Account LC Amount, Offset Clearing Document Number, SourceSystem).

The end.
