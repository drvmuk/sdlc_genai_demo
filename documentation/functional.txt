Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD) and adhering to the specified template:

**1. Requirement ID**
FR-FIN-001

**2. Title**
Load Finance Data from Everest ECC into Finance Table

**3. Description**
The system must load finance data from Everest ECC source tables (FAGLFLEXA and BSEG) into the Finance table, applying specified filters, joins, and transformation logic.

**4. Preconditions**
- Source data is available in Everest ECC tables FAGLFLEXA and BSEG.
- RLDNR = '0L' in FAGLFLEXA.
- FY parameter (Fiscal Year) is provided.
- Posting Period parameter is provided.
- Golden views (Entity, GL, Trading Partner) are available and up-to-date.
- BPC exchange rates (s_shared.v_actual_exchange_rate_bpc) are available.

**5. Main Flow / Functional Steps**

1. **Retrieve Source Data**
   - Join FAGLFLEXA with BSEG on DOCNR = BELNR, RBUKRS = BUKRS, and RYEAR = GJAHR where XBILK = 'X'.

2. **Apply Filters**
   - Filter records where RLDNR = '0L'.
   - Exclude records where RBUKRS starts with '8%'.

3. **Transform Data**
   - Map FAGLFLEXA.RYEAR to SourceFiscalYear.
   - Map FAGLFLEXA.POPER to SourcePeriod.
   - Map FAGLFLEXA.DOCNR to DocumentNumber.
   - Map FAGLFLEXA.RBUKRS to CompCode (after excluding those starting with '8%').
   - Derive LegalEntity from CompCode using Entity golden view and exclude archived Golden Entity values.
   - Map FAGLFLEXA.RACCT to GLAccount if it belongs to realized/unrealized golden accounts.
   - Convert FAGLFLEXA.RACCT to GoldenGLAcct using golden GL view.
   - Map FAGLFLEXA.RASSC to TradingPartner.
   - Convert FAGLFLEXA.RASSC to GoldenTradingPartner using golden trading partner view.
   - Calculate GainLossGC using GainLossLC and BPC exchange rate (AVG) for FiscalYearPeriod.
   - Derive LocalCurrency from Entity view and apply it to calculate GainLossLC (HSL).
   - Derive TransactionCurrency from RTCUR and apply it to calculate GainLossTC (TSL).
   - Determine OffsetAccount based on the logic for Realized/Unrealized accounts and BSEG data.
   - Convert OffsetAccount to GoldenOffsetAccount using golden GL view.
   - Map BSEG.DMBTR to Offset Account LC Amount.
   - Map BSEG.WRBTR to Offset Account TC Amount.
   - Map BSEG.AUGBL to Offset Clearing Document Number.

4. **Load Data into Finance Table**
   - Insert transformed data into the Finance table.

5. **Audit and Logging**
   - Log the number of records processed and any errors encountered during processing.

**Additional Requirements/Notes**

- Ensure data consistency and integrity during the loading process.
- Handle potential errors gracefully, logging issues for further investigation.
- The system should be able to handle large volumes of data efficiently.
