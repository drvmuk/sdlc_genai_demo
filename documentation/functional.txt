### Functional Requirement Document (FRD)

#### Requirement ID
FR-SQG-001

#### Title
Generate SQL Query for Sales Orders Data Integration

#### Description
The system must generate a complete SQL SELECT statement that integrates sales orders data from various source tables into intermediate and main tables, applying specified transformation logic, joins, and filters.

#### Preconditions
- The input mapping documents for `sales_orders_comp_stg` and `sales_orders_comp` are available and correctly formatted.
- The source tables (`b_source.ord_hdr`, `b_source.ord_dtl`, `s_master.sale_orders`, etc.) exist in the database and contain the required data.
- The database system supports the SQL syntax and functions used in the generated query.

#### Main Flow / Functional Steps

1. **Generate SQL for Intermediate Table `sales_orders_comp_stg`**
   - Create a SQL SELECT statement that retrieves data from `b_source.ord_hdr` and `b_source.ord_dtl`.
   - Apply the specified transformation logic for each column (e.g., `CONCAT(referenceto,refno)` for `CompOrderNumber`).
   - Join `b_source.ord_hdr` and `b_source.ord_dtl` on the specified conditions (`trim(a.referenceto)=trim(b.referenceto)` and `trim(a.refno)=trim(b.refno)`).
   - Filter out records where `delete_flag = 'D'`.

2. **Generate SQL for Main Table `sales_orders_comp`**
   - Create a SQL SELECT statement that retrieves data from `s_master.sale_orders` and other related tables (`b_source.ord_addr`, `b_source.ord_channel`, etc.).
   - Apply the specified transformation logic for each column (e.g., `CASE` statement for `CompSiteId`).
   - Perform LEFT JOINs with other tables based on the specified join conditions.
   - Filter records based on the condition `delete_flag <> 'D'` and `year(cast(to_date(from_unixtime(unix_timestamp(cast(a.processed_date as string), 'yyyyMMdd'))) as date)) >= year(current_date()) - 3`.

3. **Ensure Correct Data Types and Formatting**
   - Apply correct data type conversions (e.g., date conversions using `cast(to_date(from_unixtime(unix_timestamp())) as date)`).
   - Ensure that numeric fields are formatted correctly (e.g., `decimal(17,4)` for quantity fields).

4. **Handle Conditional Logic**
   - Implement IF and CASE statements as specified in the transformation logic (e.g., for `CompRelatedOrderNumber` and `CompSalesDistributionChannel`).

5. **Format the SQL for Readability**
   - Use indentation and line breaks to make the generated SQL query readable.

#### Detailed SQL Generation Steps for `sales_orders_comp_stg`

* The system shall generate the following SQL statement for creating `sales_orders_comp_stg`:
```sql
SELECT 
    CONCAT(a.referenceto, a.refno) AS CompOrderNumber,
    a.stndard AS CompOrderType,
    b.bdcob AS CompSalesOrgCompanyCode,
    b.seqnumber AS CompLineNumber,
    CONCAT(a.custhead, a.custdtl) AS CompShipToNumber,
    CONCAT(a.cusnum, a.cusa) AS CompSoldToNumber,
    b.prodmatnum AS CompMaterialNumber,
    b.ordstline AS CompOrderStatusLineLast,
    a.ordsthdr AS CompOrderStatusHeader,
    a.osrc AS CompPoDocType,
    a.cref AS CompCustomerPo,
    IF(TRIM(a.refno) <> '' AND a.refnp <> 'NA', CONCAT(a.reftp, a.refntp), '') AS CompRelatedOrderNumber,
    IF(TRIM(a.reftpo) <> '', a.reftpo, '') AS CompRelatedOrderType,
    b.ordq AS CompOrderQuantityOriginal,
    b.ordq AS CompOrderQuantityBase,
    b.tcqt AS CompCancelledQuantityOriginal,
    b.tdqt AS CompDeliveredQuantityOriginal,
    (b.ordq - b.tcqt - b.tdqt) AS CompOpenQuantityOriginal,
    (b.ordq - b.tcqt - b.tdqt) AS CompOpenQuantityBase,
    a.curchtyp AS CompCurrencyType,
    b.totalpric AS CompTotalPriceLocal,
    b.upbc AS CompUnitPriceLocal,
    CAST(TO_DATE(FROM_UNIXTIME(UNIX_TIMESTAMP(CAST(a.dateupd AS STRING), 'yyyyMMdd'))) AS DATE) AS CompCreateDate,
    CAST(TO_DATE(FROM_UNIXTIME(UNIX_TIMESTAMP(CAST(b.datecr AS STRING), 'yyyyMMdd'))) AS DATE) AS CompPromisedDeliveryDate,
    CAST(TO_DATE(FROM_UNIXTIME(UNIX_TIMESTAMP(CAST(b.dtdel AS STRING), 'yyyyMMdd'))) AS DATE) AS CompRequestedDeliveryDate,
    CONCAT(a.cusn, a.cusa) AS CompPayerNumber,
    CONCAT_WS('-', b.exttx, CAST(b.seqne AS STRING)) AS CompOrderLineExtnCode
FROM 
    (SELECT * FROM b_source.ord_hdr WHERE delete_flag <> 'D') a
LEFT JOIN 
    b_source.ord_dtl b
ON 
    TRIM(a.referenceto) = TRIM(b.referenceto) AND TRIM(a.refno) = TRIM(b.refno)
WHERE 
    a.delete_flag <> 'D';
```

#### Detailed SQL Generation Steps for `sales_orders_comp`

* The system shall generate a SQL statement for creating `sales_orders_comp` by integrating data from `s_master.sale_orders` and applying specified transformations and joins.

```sql
SELECT 
    -- Columns as per the mapping document for sales_orders_comp
    a.OrderNumber AS CompOrderNumber,
    a.OrderType AS CompOrderType,
    -- Other columns with their respective transformations
    -- ...
    IF(a.curch = 'USD', 1, cur.exchange_rate) AS CompExchangeRate,
    CAST(TO_DATE(FROM_UNIXTIME(UNIX_TIMESTAMP(CAST(cur.from_date AS STRING), 'yyyyMMdd'))) AS DATE) AS CompExchangeDate
    -- Other columns...
FROM 
    s_master.sale_orders a
    -- LEFT JOINs with other tables as specified
    LEFT JOIN (SELECT StdValue FROM s_master.ord_reg WHERE TRIM(Type) = 'ALL' AND TRIM(RegCode) = 'SOURCE_SYSTEM_CODE' AND TRIM(sourceSystem) = 'GLOBAL' AND TRIM(sourceSystemValue) = 'SAP') reg
    -- Other JOINs...
    LEFT JOIN s_master.currency cur ON TRIM(a.CurrencyType) = TRIM(cur.FromCurrency)
WHERE 
    a.delete_flag <> 'D' AND YEAR(CAST(TO_DATE(FROM_UNIXTIME(UNIX_TIMESTAMP(CAST(a.processed_date AS STRING), 'yyyyMMdd'))) AS DATE)) >= YEAR(CURRENT_DATE()) - 3;
```

#### Post-Conditions
- The generated SQL queries are syntactically correct and executable on the target database system.
- The data integration process for `sales_orders_comp_stg` and `sales_orders_comp` is successfully completed, and the target tables are populated with the transformed data.
